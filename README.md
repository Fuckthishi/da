# BodyBuilding AI 💪

A free bodybuilding transformation platform.

## Vision
Combine workout tracking, progress monitoring, gamification and AI coaching into one fitness app.

## Tech Stack
- Next.js
- Tailwind CSS
- Supabase
- GitHub
- Vercel

## MVP Features
- User profiles
- Workout tracking
- Progress photos
- Weight tracking
- XP and levels
- AI coach (future)
